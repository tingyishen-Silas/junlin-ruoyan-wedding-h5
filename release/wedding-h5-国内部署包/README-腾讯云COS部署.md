# 婚礼 H5｜国内微信部署说明

此包是纯静态网站，不需要数据库、服务器或安装任何软件。解压后，将包内的 **`index.html` 和 `assets` 文件夹** 上传到对象存储的根目录即可。

## 推荐方案：腾讯云 COS + CDN + 自有域名

这是面向微信宾客最稳妥的正式方案。建议使用一个自己的 HTTPS 域名，例如 `wedding.example.com`，而不是继续使用 `chatgpt.site`。

### 1. 创建 COS 存储桶

1. 登录 [腾讯云对象存储 COS](https://console.cloud.tencent.com/cos)。
2. 创建存储桶，地域建议选择「上海」或离宾客较近的中国大陆地域。
3. 访问权限选择「公有读、私有写」。网站只有公开读取的图片和 HTML，不包含后台数据。

### 2. 上传本包内容

1. 解压 `wedding-h5-国内部署包.zip`。
2. 打开解压后的 `wedding-h5-国内部署包` 文件夹。
3. 将文件夹里面的内容上传到 COS 存储桶根目录，上传后应是：

```text
存储桶根目录
├── index.html
└── assets/
    ├── resort-map.png
    └── transport-guide.jpg
```

> 请不要把整个 `wedding-h5-国内部署包` 文件夹再套一层上传，否则首页地址会找不到 `index.html`。

### 3. 启用静态网站

在 COS 存储桶的「基础配置」中打开「静态网站」：

- 默认首页：`index.html`
- 错误文档：可留空，或也填写 `index.html`

保存后，可先用 COS 提供的网站访问地址在手机浏览器测试首页、地图图片及三个功能页是否能正常打开。

### 4. 接入域名与 HTTPS（正式分享建议完成）

1. 准备一个自己的域名；可用二级域名，例如 `wedding.你的域名.com`。
2. 在腾讯云 CDN 中添加该域名，源站选择此 COS 存储桶。
3. 按 CDN 提示在域名 DNS 中添加 CNAME 解析。
4. 在 CDN 的 HTTPS 配置中申请并启用免费 SSL 证书。
5. 用 `https://你的域名/` 在微信中打开测试。

中国大陆域名接入 CDN 通常需要完成 ICP 备案；如尚未备案，可先使用 COS 的默认地址做内部测试，再根据婚礼日期预留备案时间。

## 微信上线前检查

1. 关闭 Wi‑Fi，使用手机流量打开 HTTPS 链接。
2. 在微信聊天中把链接发给自己，再从聊天气泡打开。
3. 分别检查「路线导航」「仪式时间」「新人时间」与两张地图图片。
4. 请一位不在同一网络的朋友测试打开，确认不会出现拦截页后再群发。

## 分享方式

在微信中打开最终 HTTPS 链接，点击右上角「…」即可「发送给朋友」或「分享到朋友圈」。

## 后续内容更新

日后如果只改文字或图片，替换 COS 中同名的 `index.html` 或 `assets` 文件即可。若接入了 CDN，请在 CDN 控制台刷新 `index.html` 和 `assets/*` 的缓存；宾客重新打开链接即可看到最新版。
